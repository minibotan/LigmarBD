# Данные мира

`dist/data/world-manifest.json` перечисляет файлы, количество записей и правила разрешения ссылок. Версия схемы 3.

В `world-battles.json` и `world-battles-special.json` копии мобов заменены объектами `{"MobTemplateID": "идентификатор"}`. Ссылка разрешается по полю `ID` в `world-mob-templates.json`. Это относится к спискам MobTemplates, хранителям LocationKeeper, мобам волн Hexes/Rounds/Mobs/MobTemplate и расписаниям BossSpawnSchedules/MobTemplate.

Остальные поля, количества, координаты, волны и расписания не изменены. Пустые записи хранителей с пустым ID сохранены как есть: они не являются ссылками. Базовые характеристики уровней в world-mob-bases.json остаются отдельными данными.

Перед заменой проверено полное равенство 3020 вложенных объектов записям общего каталога. Создано 2986 ссылок: часть проверенных объектов вложена в другие заменённые шаблоны; после замены обратное восстановление даёт исходный документ без изменений.


## Группы локаций

- `world-battles.json`: 26 основных записей с Type `location`, `party_dungeon`, `guild_dungeon`, `temple`.
- `world-battles-special.json`: 58 остальных записей — квестовые и номерные подвалы, обучение, кладбище и поле битвы.

Для полного набора Battles нужно объединить оба массива. Состав записей и ссылки на мобов не меняются; ID уникальны между файлами.
