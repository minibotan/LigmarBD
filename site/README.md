# LigmarBD — сайт

Фанатский неофициальный инструмент по Ligmar. Проект находится в активной разработке; данные и расчёты могут уточняться по новым проверкам.

## Запуск

Из корня репозитория:

```text
python3 -m http.server 4181 --bind 127.0.0.1 --directory site/dist
```

Открыть `http://127.0.0.1:4181/`. Запуск через `file://` не поддерживается, поскольку данные загружаются отдельными JSON-файлами.

Публичная версия: `https://minibotan.github.io/LigmarBD/`. Публикация выполняется GitHub Actions из `site/dist` только после отправки изменений в `master`.

## Разделы

- `#home` — главная.
- `#characters` — сохранённые персонажи, экипировка, характеристики, навыки и активные баффы.
- `#dps` — цели, ротации, пресеты и расчёт урона.
- `#library` — прогресс библиотеки T4/T6/T8.
- `#workshop` — мастера, скидки и стоимость действий.
- `#worlds` — локации, карты и противники.
- `#guides` — каталог гайдов.
- `#guides/dot` — гайд по периодическому урону.
- `#guides/enhancement` — гайд и калькулятор заточки.

## Текущая структура

- `dist/app.js` — загрузка приложения, роутинг и интерфейс персонажей; файл перегружен и запланирован к разделению.
- `dist/model.js` — предметы и итоговые параметры персонажа.
- `dist/dps.js`, `dist/dps-ui.js` — модель и интерфейс DPS-трекера.
- `dist/library-model.js`, `dist/library-ui.js` — библиотека.
- `dist/workshop-model.js`, `dist/workshop-ui.js` — мастерская.
- `dist/worlds-ui.js`, `dist/worlds.css` — миры и карты.
- `dist/guides/` — каталог гайдов, отдельные страницы и связанные с ними модели.
- `dist/guides/README.md` — правила оформления и подключения новых гайдов.
- `dist/data/` — справочные JSON сайта.
- `tests/` — проверки моделей, данных и миграций.

`dist` пока одновременно является исходной и публикуемой папкой. Её разделение запланировано после завершения двух текущих гайдов.

## Сохранения

Пользовательские данные хранятся в `localStorage` и разделены по подсистемам: персонажи, общие баффы, DPS-пресеты, библиотека и мастерская. Персонажей можно экспортировать и импортировать. Синхронизация через Google Drive пока не реализована.

## Достоверность данных

Основные формулы и проверенные механики описаны в `лигмар/ФОРМУЛЫ_ИГРЫ.md` и `лигмар/МЕХАНИКИ.md`. Предположения и экстраполяции должны быть подписаны в интерфейсе. Актуальный контекст заточки находится в `dist/guides/ENHANCEMENT.md`, камней — в `GEMS.md`.

## Проверки

```text
node --test site/tests/*.test.js
```

Текущая серия проверок проходит. Исторические результаты ручной браузерной проверки находятся в `VERIFICATION.md`; этот файл не следует считать подтверждением более поздних страниц без новой визуальной проверки.
