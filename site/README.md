# LigmarBD — локальная версия сайта

Запуск из этой папки: `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`.
Открыть http://127.0.0.1:4173/ . Нужен HTTP-сервер, открытие index.html через file:// не поддерживается.

Главная и раздевалка: 6 классов, 10 слотов, 87 записей каталога, поиск, качество, заточка +0…+12, до трёх дополнительных свойств; распределение очков; расчёт атаки, брони, сопротивления, меткости, уклонения, КШ и ВА; ручные баффы. Локальное сохранение одного текущего персонажа, экспорт/импорт JSON с проверкой формата. Для нескольких билдов использовать отдельные экспортированные файлы.

HP/мана: без заданной пользователем базы выводятся только прибавки; автоматический прирост с уровнем неизвестен. Значения исходных HP/маны относятся к персонажу данного уровня с 5 соответствующего стата и без вещей. После смены уровня или класса исходные значения автоматически сбрасываются: их нужно задать заново. Бафф атаки — добавка AttackMultiplier (жрец); отдельный эффект мага не учтён. Камни, ротации, синхронизация Google Drive — последующие этапы.

`dist/model.js` — расчёт отдельно от интерфейса; `dist/app.js` — навигация, редактирование, хранение. Никаких внешних запросов для работы сайта. Каталог содержит 87 записей; 19 легендарных чертежей входят в 87 записей, поэтому это не 87 уникальных типов вещей. Прогресс библиотеки в исходном каталоге — снимок, а не данные нового пользователя; в интерфейсе не показывается.

Ограничения: формула качества предварительная для T4; базы и диапазоны каталога могут отставать от патча; округление половин принято вверх. Требования отмечаются предупреждениями, чтобы можно было планировать ещё недоступный комплект. Проверка требований использует итоговые статы без моделирования порядка надевания. Доступны все качества как планируемые экземпляры, доступность конкретного качества в игре отдельно не гарантируется.

Для мага, лучника и воина доступны иллюстрации; для остальных классов отображаются эмблемы. Использована готовая иллюстрация класса, внешний вид не собирается по надетым вещам. Игровые изображения остаются материалами Ligmar; сайт неофициальный.

Проверки: `node --test tests/model.test.js`. Проверяются базовые статы, наблюдавшаяся заточка топора, отдельная формула защиты, аддитивные баффы и валидация импорта. Поддержка WebMCP необязательна: при наличии API зарегистрировано чтение текущего билда get_character_build.

Легендарные предметы: 19 записей из сохранённого каталога доступны через фильтр «Легендарные» в выборе слота. Золотые карточки показывают базу ×1,3, а настройка использует диапазоны именно выбранного чертежа и legendary-базу заточки. Отсутствующие в каталоге чертежи не синтезируются.

## Мои персонажи

Раздел `#characters` хранит независимые сборки в `ligmarbd.characters.v1`. Можно создавать героев, копировать текущую раздевалку, выбирать изученные умения и уровни 0–10. Уровень 0 означает «не изучено». Импорт и экспорт отдельного персонажа включают поле `skills`; старые файлы без него поддерживаются.

Каталог содержит 118 умений шести классов. Для незаполненных уровней параметры не вычисляются; выученный уровень сохраняется. Эффекты навыков и ограничение их уровня по миру пока не рассчитываются. При смене класса навыки сбрасываются; при смене мира сбрасываются экипировка и очки, а выученные навыки сохраняются.

## ДПС-трекер

Раздел `#dps`: выбор раздевалки или сохранённого героя, до восьми настраиваемых целей, последовательность умений и пауз. Планы сохраняются отдельно для каждого героя и класса в `ligmarbd.dps.v1`. В режиме сохранённого героя доступны только выученные активные умения; в режиме раздевалки уровень выбирается в строке.

По умолчанию учитываются среднее границ урона, криты и попадания. Альтернативный режим — все обычные попадания без критов. ВА сокращает каст, откат начинается после завершения. Ошибки отката не добавляют автоматических пауз. Неопределённые параметры блокируют точный итоговый DPS. Времена ошибочных строк — планируемые.

Тики DOT учитывают броню, не критуют и не проходят повторную проверку попадания. При обновлении того же DOT остаток отменяется с вероятностью успешного наложения. В суммарном уроне строки учитывается именно оставшийся вклад этого применения. Отдельно показаны урон/DPS до конца кастов и с хвостом DOT.

Alt показывает исходное время каста; в подсказке урона — значения до брони и срезанную часть для каждой цели. Массовое попадание задаётся числом целей; позиционирование и лимиты радиуса пока не моделируются. Мана, входящий бой, автоатаки, смерть целей и синхронизация уровня навыков по миру не моделируются. Неопределённые изменения боевых статов и триггерные эффекты помечаются явно.
