# Предварительное автоизучение

Кнопка «Изучить всё» заполняет уровни навыков текущего персонажа. Недоступные навыки получают уровень 0. Учитывается уровень персонажа, ограниченный максимумом мира; стоимость обучения и требования статуса пока не учитываются.

Известные требования ранга имеют приоритет. Для пропущенных рангов используется медианный шаг между известными рангами и ближайший известный ранг как опорная точка. Если шаг нельзя вычислить, принимается +5 уровней персонажа для навыков, открываемых до уровня 40, и +4 для навыков с уровня 40. При отсутствии опорных рангов первый навык с открытием на уровне 1 использует требования 1, 5, 10 и далее.

Это разрешённая предварительная экстраполяция; её нужно уточнить. JSON каталога не дополняется вымышленными подтверждёнными требованиями.


## Лечение в карточках

Численные слагаемые лечения записаны в `healing` рангов навыков. Прямое лечение использует среднюю магическую атаку, плоскую прибавку и/или максимальное HP текущего героя. Расчёт на одну цель, без оверхила и без критов: правило критов лечения пока не подтверждено.

Для HPS прямое лечение делится на каст с ВА плюс откат. Для лечения со временем предварительно предполагается обновление без сложения: полный объём делится на максимум длительности эффекта и цикла. Это средняя оценка, без моделирования дискретных тиков лечения. По Alt отображается полный объём за применение.

Вампиризм зависит от нанесённого урона; спасение от смерти условно. Постоянный HPS для них не рассчитывается. Их описания и условия остаются видны.
