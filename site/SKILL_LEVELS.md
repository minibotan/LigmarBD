# Каталог умений

Полные записи хранятся в `dist/data/skills-<owner>.json`: mage, priest, warrior, guardian, assassin, archer, mob, account, special. Список файлов находится в `skills-manifest.json`. Всего 1518 записей уровней, 146 уникальных умений. Оригинальные поля каждой записи сохранены без изменений.

`dist/skill-catalog.js` преобразует записи в модель интерфейса при загрузке. Наносекунды переводятся в миллисекунды для каста/отката и секунды для эффектов. Периодический урон в BattleStats задаёт урон одного тика; для существующей модели рассчитывается сумма за длительность. Базовый компонент атаки определяется по описанию. Четыре автоатаки создаются адаптером как технические действия.

Все классовые ранги 1–10 и их требования доступны явно; экстраполяция для них не нужна. ID сохранены для совместимости изученных навыков и ротаций.

Файлы содержат больше механик, чем умеет симулятор. Флаги и исходные эффекты сохраняются в JSON; неизвестные алгоритмы не выводятся из названия флага. Расход текущего HP и урон призванных существ помечаются нерассчитанными. Эта замена не устанавливает PvP-множитель DOT или правила срабатывания дополнительного магического урона.
