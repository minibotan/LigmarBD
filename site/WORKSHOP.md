# Мастерская

Состояние мастеров и выбранные параметры сохраняются в `ligmarbd.workshop.v1`. Прогресс библиотеки читается из `ligmarbd.library.v1` при открытии раздела. Ювелир отображается отключённым.

Кузнец работает с оружием, портной с бронёй и плащами, ремесленник с украшениями. Уровень и текущий опыт вводятся независимо; автоматический переход уровня не выполняется.

Суммарная скидка = мастер + чертёж + библиотека. Без выбранного предмета скидка чертежа не учитывается. Материалы: `ceil(base * (1 - discount / 100))`. Базовые строки расходов уже учитывают тип предмета: повторно умножать их нельзя.

При обычной ковке/плавке предмета с древним свойством осколки: `ceil(tier * typeMultiplier * (1 - discount / 100))`. Слеза для возврата ковки — 1; при плавке — число заблокированных свойств в квадрате. Древняя плавка использует коэффициенты из JSON без скидок.

Расходы Т8 и серебра неизвестны, не экстраполируются. Неизвестная скидка мастера оставляет итоговую цену материалов неизвестной; фиксированные расходы показываются. Уровень 0 чертежа означает неизученный рецепт, отображаемая цена предназначена для планирования.
