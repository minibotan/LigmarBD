## Формат и правила работы

JSON UTF-8. Поле `rows` — таблица: массив строк-объектов с одинаковыми именованными колонками. Вложенные списки и объекты оставлены структурированными, чтобы не терять требования, несколько целей и ограничения оружия. `null` означает неизвестное значение, не ноль.

Одна строка — **одно наблюдение определения умения определённого уровня в конкретном контексте**. Одинаковые skill_id и skill_level могут повторяться: не суммировать такие строки и не удалять их вслепую. Сначала выбрать нужный контекст и сверить определения. Активный персонаж и сезонный персонаж могут быть одним и тем же персонажем; их определения сохранены раздельно.

| Колонки | Значение |
|---|---|
| skill_id, name_ru, name_en | Идентификатор шаблона и названия  |
| variant | `effective`: действующее определение; `next`: следующий предложенный уровень; `metadata_only`: только сведения об умении |
| skill_level | Уровень конкретного определения, которому соответствуют числа в строке |
| learned_level | Выученный уровень из записи персонажа; effective.level учитывает ограничение уровня младшего мира и может быть ниже. У пяти неизученных навыков лучника learned_level=0, а effective.level=1 — предварительный просмотр, не доступный для применения навык |
| max_level | Максимальный уровень, указанный в записи |
| unlock_character_level, unlock_status_level | Начальные требования внешней записи умения |
| type, targets, range, weapons | Тип, цели, дальность-категория и допустимые типы оружия: обозначения типов |
| activation_time_ms, cooldown_ms | Время применения и откат в миллисекундах; не пересчитаны через ВА персонажа |
| mana_cost, consumables | Расход маны и предметов при применении |
| rank_requirements | Требования именно этого уровня: уровень персонажа, статус, предметы и, если есть, здания |
| description_ru, description_en | Описания без HTML; сохраняют урон, множители, длительности и условия действия |
| context | `account_character`, `active_character`, `season_character`, `account_library` |
| context_character_level | Уровень персонажа в соответствующем снимке; для библиотеки null |
| raw_definition | Полное определение, включая исходные HTML-описания |
| raw_wrapper_metadata | Неизменённые поля внешней записи, кроме effective и next |

Идентификаторы предметов в требованиях — идентификаторы шаблонов, не личных экземпляров. HTTP-заголовки, токены, личные сообщения и данные инвентаря в таблицы не копируются.

Для расчётов не смешивать базовый урон, добавочный урон, процент от снаряжения и урон за длительность. Откат не равен времени применения. По одному описанию не считать все эффекты разовым уроном, не выводить фактический DPS без модели боя.

## Обновление таблиц

`extract_skills.py` обновляет таблицы из входного JSON: `python extract_skills.py input.json`. Повторный запуск перезаписывает шесть таблиц; после обновления нужно сверить сводку покрытия.

Правила для расчётов: [МЕХАНИКИ.md](МЕХАНИКИ.md). Ограничения и необходимые дополнительные данные: [ПРОБЛЕМЫ.md](ПРОБЛЕМЫ.md).
