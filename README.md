# LigmarBD

База данных и планируемый сайт по Ligmar. Первая локальная версия главной и раздевалки реализована в `site/`.

## Материалы

- `лигмар/` — шесть таблиц классовых умений, формулы игры, механики, анализ умений, журнал уточнений, доказательства и читаемые логи двух боёв, иллюстрации формул.
- `exports/ligmar-json/` — справочники мобов, локаций, библиотеки, способностей и изображения предметов; покрытие описано в `manifest.json` этого каталога.
- `build-tiers.md` — договорённости по тирам билдов.
- `equipment-quality-formula.md` — заметки о качестве предметов.
- `outputs/ligmar_code_data/` — таблица правил версии v0.40.509 и результаты её инспекции. Это исторический снимок.
- `work/ligmar_code_data/` — исходный скрипт формирования этой таблицы и её превью. Скрипт требует `@oai/artifact-tool`.
- `PROJECT_PLAN.md` — согласованный функционал сайта и сохранений.
- `MIGRATION_MANIFEST.json` — перечень файлов.

## Ограничения

Данные относятся к разным версиям игры. Актуальные правила модели: `лигмар/ФОРМУЛЫ_ИГРЫ.md`. Предположения и экстраполяции не считать проверенными механиками.

Репозиторий: https://github.com/minibotan/LigmarBD, основная ветка — `master`.

## Запуск сайта

Из `site/`: `python3 -m http.server 4173 --bind 127.0.0.1 --directory dist`, затем открыть http://127.0.0.1:4173/ . Возможности и ограничения: [site/README.md](site/README.md). Результаты проверок: [site/VERIFICATION.md](site/VERIFICATION.md).

## GitHub Pages

Адрес после включения Pages: https://minibotan.github.io/LigmarBD/ .
В Settings → Pages выбрать Source: GitHub Actions. Workflow `Publish LigmarBD` проверяет расчёты и публикует только `site/dist` при изменениях сайта в `master`; доступен ручной запуск.
Сохранения остаются локальными для браузера и адреса сайта. Для переноса с localhost используйте «Скачать билд» и «Загрузить».
