Уточнение топ тира: у всех вещей все свойства подходят; вторая половина вещей имеет древнее свойство и два свойства по 90%, а не случайный неподходящий стат.

## Ограничения текущего сравнения мага

- Маг остаётся 52-го уровня в текущем снаряжении, кроме четырёх замен на лёгкую броню: голова, грудь, ноги и ступни.
- Рассматриваются отдельно хай и топ тир; мид исключён из текущего сравнения. Правила тира применяются только к четырём новым вещам.
- Для четырёх новых вещей топ тира: две имеют допстаты 150% / 100% / 100%, две — 150% / 90% / 90%; все свойства подходят. Допускаются легендарные вещи, в том числе 150% / 90% / 90%. Базовая заточка новых вещей +6, заполнены все доступные ячейки для камней.
- Оружие, перчатки, плащ и бижутерия сохраняются в текущем состоянии, включая их заточки, свойства и камни.
- ВА важен: волшебные перчатки и бижутерия ради него не меняются.
- В задаче с тотемом допускается при необходимости повысить заточку новых вещей ради HP. Это отдельное допущение расчёта, а не изменение общей таблицы тиров.
- Для текущих расчётов камни — T6. Общее определение тиров само по себе уровень камней не задаёт.
