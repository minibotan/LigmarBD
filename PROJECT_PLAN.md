# Сайт LigmarBD: согласованный объём


## Итоговый продукт

1. Раздевалка: экипировка персонажа с расчётом итоговых характеристик.
2. DPS-чек: настройка ротаций на основе одетого персонажа.
3. Гайды по механикам.
4. Просмотр мобов и информации о них.
5. Просмотр и отслеживание личного прогресса библиотеки, аналогично существующей таблице пользователя.

## Сохранение

- MVP: полноценная локальная версия; сохранения в браузере, экспорт и импорт файла.
- Итог: дополнительно синхронизация личных данных через Google Drive, между устройствами пользователя.
- Подключение Google необязательно; локальная работа сохраняется.
- Общие справочники игры отделены от личных билдов, ротаций и прогресса.
- Формат сохранений должен иметь версию для дальнейших миграций.

## Предложения, ещё не утверждённые как этапы разработки

Начать с раздевалки мага, сверить расчёты с известным персонажем, затем добавить ротации и противника. Для ротаций предложены последовательность и приоритеты с условиями; для проверки — лента событий боя. Выбор стека, дизайн, точный объём первого этапа и архитектура синхронизации ещё не согласованы.
